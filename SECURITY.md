# Security Policy

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting
("Security" tab, "Report a vulnerability") on this repository.

Include steps to reproduce, the affected version or commit, and the impact.
You will get an acknowledgement within 7 days.

## Supported versions

Only the latest release on `main` receives security fixes while the project is below 1.0.

## Scope and background

The threat model and known limits are in `docs/SECURITY_AUDIT.md` and `docs/KNOWN_LIMITS.md`.
